# Control metric: the window of separation

`SKILL.md` defines separation: the difference in the target metric between a segment and the rest of the
base, on the reachable base and under the same treatment. It says why each of those three conditions
carries weight, which signals are not the control metric, and what to answer when someone asks what is
normal. This file sets the window, where it is counted from on both sides, and how often you take a value.

## The window

The window is the target metric's own, as its definition in `metric-definitions` states it,
counted from the same send or the same period start on both sides. Take one value per review
cycle.
